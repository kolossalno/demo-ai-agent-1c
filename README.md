# DemoAIAgent: Автономный ИИ-агент на 1С:Предприятие 8

Демонстрационная внешняя обработка для платформы «1С:Предприятие 8» (8.3.20+), реализующая паттерн **ReAct (Reasoning + Acting)** и протокол **Tool Use / Function Calling** (совместимый со спецификацией OpenAI API). Цель создания - показать сотрудникам/программистам 1С универсальность и простоту протокола взаимодействия с LLM

---

## 📌 О проекте

Обработка демонстрирует концепцию автономного взаимодействия больших языковых моделей (LLM) с сервером 1С:

* LLM сама решает, какие действия на сервере 1С ей необходимы для решения задачи.
* 1С выполняет запрошенные серверные функции и передает результаты обратно модели в цикл рассуждений.
* Все операции осуществляются штатными средствами платформы (HTTPСоединение, ЗаписьJSON, ЧтениеJSON) без внешних компонент.

---

## 🚀 Быстрый старт

### 1. Требования

* Платформа «1С:Предприятие» версии **8.3.20** или выше (протестировано на 8.3.25 и 8.5).
* Доступ к любому OpenAI-совместимому серверу LLM:
  * **Ollama** (локально): `http://localhost:11434/v1/chat/completions` (модели: `qwen2.5-coder`, `llama3.1`)
  * **LM Studio** (локально): `http://localhost:1234/v1/chat/completions`
  * **OpenAI API**: `https://api.openai.com/v1/chat/completions`
  * **DeepSeek API**: `https://api.deepseek.com/chat/completions`

### 2. Запуск в 1С

1. Скачайте готовую обработку из папки `build/DemoAIAgent.epf`.
2. В режиме «1С:Предприятие» откройте файл через главное меню: **Файл → Открыть**.
3. Укажите адрес API, ключ (при необходимости) и имя модели.
4. Введите задачу и нажмите кнопку **«Запустить агента»**.

## 🛠 Доступные инструменты агента (Tools)

Агент передает LLM массив доступных функций:

1. **`get_os_info`** — возвращает сведения о сервере: тип операционной системы, разрядность и версию платформы 1С.
2. **`list_files`** — получение списка файлов и папок в текущем каталоге с поддержкой масок поиска (например, `*.txt`, `*.*`).
3. **`change_directory`** — смена текущего рабочего каталога (поддерживает переход на уровень выше `..`, переход в подкаталоги и абсолютные пути).

## 📦 Версии обработки

* **`build/DemoAIAgent.epf` (v1)** — классическая синхронная реализация ReAct-цикла в модуле объекта. Рекомендуется для изучения архитектуры паттерна.
* **`build/DemoAIAgent_v2.epf` (v2)** — интерактивная версия с пошаговым таймером, кнопкой прерывания и визуализацией схемы инструментов в формате HTML/JSON с динамической анимацией активного инструмента (не доделана).

## 🔧 Сборка из исходников

Для сборки обработок из XML-исходников запустите скрипт PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Version all
```

Скрипт автоматически найдет установленную платформу 1С, создаст временную информационную базу и соберет EPF-файлы в каталог `build/`.
